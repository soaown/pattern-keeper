변경: PDF를 한 번 열면 IndexedDB에 보관하여 같은 기기/브라우저에서 재접속 시 자동 복원합니다.
설정 > 저장된 PDF 삭제: PDF 캐시만 지우고 완료 기록은 유지합니다.
기존 DMC 색상, 도안 표시, 진행률, Supabase 코드는 유지했습니다.

주의: PDF 자동 복원은 기기별 브라우저 저장입니다. 다른 기기에서 PDF까지 자동 복원되지는 않습니다.
Supabase 진행률 동기화는 로그인 상태와 네트워크에 따라 달라집니다.
Safari 비공개 브라우징 또는 사이트 데이터 삭제 시 로컬 PDF가 사라질 수 있습니다.

모든 파일을 같은 폴더에 넣으세요. 새 pdf-cache.js가 필요합니다.
